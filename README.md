# Amazon Sales Data India

### Data Analytics & Business Intelligence

An end-to-end sales analysis project using Google Sheets to transform retail transaction data into meaningful business insights through KPI tracking, data analysis, and visualisation.

## Project Objectives

- Analyse total sales, profit, and profit margin.
- Track monthly sales and profit trends.
- Identify top-performing product categories and products.
- Analyse order statuses, returns, and cancellations.
- Compare payment methods and fulfillment channels.
- Evaluate state-wise sales and profitability.
- Present business performance through an executive dashboard.

## Tools & Technologies

- Google Sheets
- Spreadsheet formulas and summary tables
- Data Analysis
- Data Visualization
- GitHub

## Project Workflow

1. Inspect the source dataset and its columns.
2. Validate transaction records and data quality.
3. Calculate business KPIs and summary metrics.
4. Analyse category, product, payment, fulfillment, and geographic performance.
5. Build charts and an executive dashboard.
6. Summarise findings for business decision-making.

## Key Metrics

- Gross Revenue
- Net Profit
- Profit Margin
- Total Orders
- Units Sold
- Average Order Value
- Return Rate
- Cancellation Rate

## Key Business Questions

- Which product categories generate the most revenue?
- Which products contribute the most sales?
- How do sales and profits change month by month?
- Which payment methods contribute the most revenue?
- Which fulfillment channels perform best?
- Which states are the leading sales markets?

## Data Privacy

The dataset was provided for analysis. Raw transaction data should only be shared publicly with permission from its owner. This repository should contain only approved project materials.

## Disclaimer

This project analyses the available dataset for educational and business analytics purposes. Findings reflect the supplied records and are not official Amazon business results.
